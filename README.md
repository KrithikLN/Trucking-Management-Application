# __Trucking Management Application__
This project is designed to schedule trucks based on various states and actions using the Markov's Decision Process. We have also designed an android appication to send real-time location of trucks and also location routing

## __Repository Structure:__
* MDP Python Code Directory contains all the python code used for the truck shceduling with location routing.
* The TruckingAppServer/Hawkers Directory contains the code for the java server which was used to store driver data and location data.
* The src directory contains the code for the Trucking Management Application which is built for android mobile phones

## __Technologies Used:__
* Java : Used for backend and frontend application
* Python : for truck scheduling and routing
* MySQL : For database 

## __Getting Started__

## __Requirements:__
* Java Development Kit must be installed
* Android Studio must be installed
* Python 3.XX with numpy installed
* MySQL
### __Usage:__
* Clone the repository:
  ```
  https://github.com/KrithikLN/Trucking-Management-Application.git
  ```
* The TruckingAppServer/Hawkers is a java workspace which must be run separately
* Paste the code from within the src directory in an new Project created in Android Studio within the new projects src directory
* Run the MDP.py to start the algorithm
